# Ostinato user guides

Ostinato is the movement, mining, building and combat engine under [TenorClef](https://github.com/vexrypt-rgb/TenorClef).
You can also use it on its own through chat commands with the `#` prefix.

Everything here was read from the source (`src/main/java/baritone/`, `Settings.java`). Features that exist
only on some release lines are marked.
