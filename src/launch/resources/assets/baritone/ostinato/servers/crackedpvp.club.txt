# Ostinato: auto-spectate route for crackedpvp.club. A copy at baritone/servers/crackedpvp.club.txt in the game folder
# replaces it. Steps run in order after /register or /login; menus are clicked by item names.
#   cmd /x       send a command once (rate limited)
#   hotbar word  right-click the hotbar item whose name has this word
#   click word   in the open menu, click the item whose name has this word
#   wait s       pause
#   words a,b    menu words for the fallback, best first
#   authclick prompt words | choice   during login, click the [choice] button of the chat message with these words
#                (a humanized click in chat, before /register or /login; menus wait until login is done)
# The login plugin first asks "Are you using a premium account? [✔ Yes] [✖ No]": this throwaway is cracked.
# The hub menu is Survival, Practice, FFA, Discord, Store. None of those is spectate.
# Practice opens a duel lobby. Casual and Competitive start a fight, so they are never clicked.
# After that, each hotbar item is right-clicked once in case it opens a spectate menu.
authclick premium account | no
hotbar GAMEMODES
click practice
wait 8
words spectate,spectator,spec,watch
