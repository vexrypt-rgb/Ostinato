# Ostinato: kit signatures for spectator kit detection (KitSignatures). One kit a line:
#   <label> [min=<score>] <clue>=<weight> ...
# A clue is an evidence token or a glob with * (any run of characters). What a watched fighter shows becomes tokens
# worth 0..1 each:
#   held in a hand (item id path, e.g. diamond_sword, shield, end_crystal): share of the watched time, times 5, at most 1
#   armor:<material> (leather, chainmail, iron, golden, diamond, netherite, turtle): share of the four slots and time
#   elytra, glint:armor, glint:weapon, trim, dyed: worn share of the time, the same way
#   effect:<id> (speed, strength, fire_resistance, ...): potion particles seen, share of the time
#   events, worth half each, 1 from the second on: ate:golden_apple, ate:enchanted_golden_apple, ate:food,
#     drank:potion, threw:ender_pearl, threw:splash_heal, threw:splash_harm, threw:splash_other, threw:wind_charge,
#     shot:arrow, shot:trident, pop:totem, crystal (an end crystal appears next to them), firework
# A kit's score is the sum of weight x value over its clues; the highest score wins if it reaches min (default 2.5),
# otherwise the fighter is "unknown". To add a kit, add a line; a copy of this file at baritone/spectate-kits.txt in
# the game folder replaces this one.
