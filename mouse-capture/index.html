Teach the bot your hand

Short one-minute rounds. Every mouse movement is recorded as raw counts with high-resolution timestamps, the same input Minecraft reads. Play naturally, as you would in game: don't try to be extra smooth or extra fast. Press Esc to bail out of a round. Download the JSON when you're done (it's also backed up in this browser).

Your settings

Minecraft sensitivity is the slider value (100% = default). Pointer speed is the slider in Windows Mouse settings (default 10 = middle). Cursor gain on this page is set from your DPI so targets feel about the same size in inches on any mouse.
